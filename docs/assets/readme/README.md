# README images

The image files in this folder are generated from the briefs in [`ops/readme/image-prompts.md`](../../../ops/readme/image-prompts.md). The root [`README.md`](../../../README.md) references them by the filenames given there.

Naming: `<name>-dark.png` and `<name>-light.png` for themed images (the README switches with a `<picture>` element), plain `<name>.svg` or `<name>.png` for the rest.

Until the files are generated, the README shows broken image icons. Every diagram that matters also exists as a native Mermaid block in the README, so nothing is lost.

Data charts must be reproduced from the exact numbers in the brief, not redrawn by eye.
