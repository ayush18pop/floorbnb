# A18 progress (MCP server, apps/mcp)
Branch agent/A18. Streamable HTTP, stateless, `POST /mcp`, official `@modelcontextprotocol/sdk` 1.32 (`WebStandardStreamableHTTPServerTransport`, one server+transport per request, JSON responses, no sessions). Holds no keys except the optional facilitator gas key from env.

## Tools (names match the site's /agents page and EXECUTION_PLAN A18)
Free: `get_floor_info`, `list_assets`, `get_status({owner}|{vault})`, `get_rebalance_history`, `build_create_position_tx` (deposit: unsigned USDT approve to the factory + createPosition), `build_exit_tx({vault, kind: requestClose|closeToUSDT|exitInKind, to?})` (withdraw/exit).
Paid (x402, 0.01 USD each, env-overridable, labelled "proposed"): `quote_protection`, `backtest`, `simulate_gap`.
- All inputs are strict zod objects (unknown keys rejected); every tool has an output schema, annotations (read-only) and returns structured JSON with `disclosure` (SDK `FLOOR_DISCLOSURE` + "about 24% / 1 over m, not a guarantee, spot only, past data").
- Tx tools call the API (`API_BASE_URL`, default http://127.0.0.1:8787), which simulates with eth_call. The MCP server re-checks every returned `to` (USDT or factory for create; the requested vault for exit) and refuses otherwise. It never signs.
- `backtest` reads `docs/data/gap_backtest.csv`, `docs/data/vault_path_*.csv` and `research/m_study/results/T1,T5`; it returns a data-unavailable error instead of inventing numbers. `quote_protection` and `simulate_gap` are SDK arithmetic (m = 4), labelled as such. `get_floor_info` carries the exact audit sentence from docs/AUDIT.md.
- Not built: Ondo, perps or anything beyond the nine tools; no `get_vault_info` alias.

## Paid flow
x402 v2 over MCP: unpaid call returns an `isError` result with `structuredContent` = PaymentRequired (same JSON in `content[0].text`); retry with `params._meta["x402/payment"]` (or an HTTP `PAYMENT-SIGNATURE` header). Success returns the result with `_meta["x402/payment-response"]`. The HTTP response also carries `PAYMENT-REQUIRED` / `PAYMENT-RESPONSE` headers; `MCP_HTTP_402=1` makes the unpaid answer a real HTTP 402. Input is validated by the tool schema before any payment is requested; a tool failure after payment returns an error and the gate releases the receipt without settling.
Gate: `@floor/x402` `createGate`, assets USD1 and U (EIP-3009). Receipts are in-memory (`MemoryReceiptStore`; reset on restart, the on-chain nonce still blocks replay).
`apps/api` `/v1/paid/quote` is wired through `apps/api/src/paid.ts` (`createPaidGate`) when `X402_PAYTO` is set; otherwise it stays 501. The gate's handler computes the quote itself so the response keeps `PAYMENT-RESPONSE`.

## Guards
Origin allow-list (`MCP_ALLOWED_ORIGINS`, 403; no Origin header is fine), `MCP-Protocol-Version` check (400), 64 KB body cap (413), per-IP limits 120/min all and 20/min paid-tool calls (429 + Retry-After), GET/DELETE /mcp answer 405, `TRUST_PROXY=1` for x-forwarded-for.

## Connect an agent
Claude Code: `claude mcp add --transport http floor http://127.0.0.1:8788/mcp` or `.mcp.json`:
```json
{ "mcpServers": { "floor": { "type": "http", "url": "http://127.0.0.1:8788/mcp" } } }
```
Cursor (`.cursor/mcp.json`):
```json
{ "mcpServers": { "floor": { "url": "http://127.0.0.1:8788/mcp" } } }
```
Free tools work in both. Generic clients do not pay automatically: for a paid tool the agent signs the payment with its own wallet (e.g. Binance AW `baw x402-payment`) and retries with `_meta["x402/payment"]`. Replace the URL with the deployed one (`NEXT_PUBLIC_MCP_URL` on the site).
