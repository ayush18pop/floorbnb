# A16 progress (REST API, apps/api)
Branch agent/A16. Hono + @hono/node-server, viem, zod. Holds no keys.

## Routes (all JSON; bigints are decimal strings)
GET /healthz (keeper heartbeat age or null) | GET /v1/floor | GET /v1/assets | GET /v1/market (BW3 rwa price, 15 s cache) |
GET /v1/positions?owner= | GET /v1/positions/:vault | GET /v1/keeper/runs?limit=&vault= | GET /v1/keeper/runs/:id |
POST /v1/tx/create-position (approve + createPosition) | POST /v1/tx/exit ({vault, mode: exitInKind (default) | requestClose | closeToUSDT, to?}) |
POST /v1/paid/quote (501 until a gate is injected).

Guards: zod on every input, 32 KB body cap (413), 60/min free and 10/min tx per IP (429 + Retry-After), CORS only for WEB_ORIGIN.
Every returned tx `to` must be USDT (read from factory.usdt()), the factory, or the vault. A vault counts as known only if it is in
factory.positionsOf(vault.owner()). Upstream errors answer 502 without echoing the message.

## Env
FLOOR_CHAIN_ID (56 default, 31337 allowed), FLOOR_RPC_URL or BSC_RPC_URL, FLOOR_FACTORY + FLOOR_LENS or FLOOR_DEPLOYMENT_FILE
(default packages/contracts/deployments/<chainId>.json). Startup fails with a clear message when no deployment is found.
WEB_ORIGIN (comma list), PORT (8787), TRUST_PROXY=1 (use x-forwarded-for), BW3_API_KEY / BW3_API_SECRET (without them /v1/market is 503).
Base URL for the web and MCP: the API origin, e.g. NEXT_PUBLIC_API_URL (web) and API_BASE_URL (MCP); http://127.0.0.1:8787 locally.

## Mocked vs real
- Tests: the chain is a fake PublicClient and BW3 is mocked. `pnpm --filter @floor/api test` (19 tests), typecheck and build are clean.
- Keeper runs: packages/db is a stub, so the store is an interface (`KeeperRunStore`) with an in-memory adapter that starts empty.
  Until the keeper writes into a real adapter, /v1/keeper/runs is empty and heartbeat age is null.
- x402: A17's gate is not in main. Seam: `AppDeps.paidGate(req, priceUsd) => Promise<Response | null>` (null = paid, Response = return as is).
  server.ts has the note; adapt `@floor/x402` gate() there.
- /v1/market: live BW3 rwa price works (price, referencePrice, updatedAt). The upstream row has no statusInfo for bStocks today, so
  marketStatus / nextOpenTime / reasonCode are null (DX_LOG). `vaultWindow` is computed from the SDK, not from Binance.
- create-position simulates approve with eth_call. createPosition is simulated only when the owner's allowance already covers it, else `simulation: null`.

## Run against an anvil fork (verified 2026-10-03, nothing sent to chain 56)
1. (cd packages/contracts && forge build)
2. anvil --fork-url https://bsc-mainnet.public.blastapi.io --port 8545 --chain-id 56 --silent
3. (cd apps/keeper && pnpm exec tsx scripts/fork-setup.ts http://127.0.0.1:8545)   # prints factory, lens, vault JSON
4. bash -c 'set -a; . <repo>/.env; set +a; FLOOR_CHAIN_ID=56 FLOOR_RPC_URL=http://127.0.0.1:8545 FLOOR_FACTORY=<factory> FLOOR_LENS=<lens> pnpm --filter @floor/api dev'
   (skip the .env sourcing to run without market data). For a 31337 anvil use FLOOR_CHAIN_ID=31337 and deployments/31337.json.
5. curl localhost:8787/v1/floor, /v1/positions/<vault> (real Lens: V 1000e18, floor 900e18, cushion 100e18, needsRebalance true), /v1/market, POST /v1/tx/exit.
